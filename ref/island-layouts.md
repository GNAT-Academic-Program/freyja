# Island layouts: what each datasheet proposes

The placement rules in `tools/island_profiles.yaml` are derived from the
layout examples below, not from the netlist order. Flow for any new IC: read its
layout example, add a row here with the section number, then encode the profile.
Items marked [verify] were not read from the actual figure.
