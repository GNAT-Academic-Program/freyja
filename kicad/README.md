# Current FREYA KiCad project

Open **[odin.kicad_pro](odin.kicad_pro)** in KiCad 9. The hardware is **FREYA
HW 0.1.0-proto.1**, XC7A100T-2FGG676I + RP2350B; `odin` is the retained project
basename. **[odin.kicad_pcb](odin.kicad_pcb) is the authoritative manual
layout.** Preserve its placement, routing, outline, zones and board-only holes.

Use the single [current workflow](../ref/ide-agent-prompt.md) for ownership,
checks, regeneration side effects and the recurring cleanup checkpoint.
[Current findings](../findings.md) records the measured baseline and known
check failures. The [root README](../README.md) links subsystem references.

## File map

| File | Role |
|---|---|
| `odin.kicad_pcb` | Live layout; not a disposable generator output. |
| `odin.kicad_pro`, `odin.kicad_dru` | Project settings/net classes and custom design rules. `gen_pcb.py --rules-only` rewrites generated rules plus PCB stackup/layers; it is not a read-only check. |
| `odin.kicad_sch` | Root schematic generated by `tools/gen_project.py` from `tools/design.py`. |
| `fpga.kicad_sch` | FPGA, decoupling and configuration straps. |
| `power.kicad_sch` | Input, source mux, regulators, AUX IN pass-through and monitoring. |
| `memory.kicad_sch` | Four independent 1.8 V PSRAMs, SDRAM, MRAM, microSD and configuration flash. |
| `supervisor.kicad_sch` | Board Controller sheet: RP2350B, USB-C and FPGA control. |
| `slots.kicad_sch` | Eight direct and two buffered sections, rail selection and branch protection. |
| `network.kicad_sch` | RTL8211FDI-CG gigabit PHY/ETH and raw LVDS LINK P/Q. |
| `video.kicad_sch` | HDMI output through TPD12S016. |
| `odin.net` | KiCad export of the generated schematic; PCB synchronization reads this file. |
| `odin.kicad_sym`, `odin.pretty/` | Generated custom project symbols/footprints. |
| `sym-lib-table`, `fp-lib-table` | Select the custom, imported and system libraries. |
| `odin.kicad_prl`, `fp-info-cache` | Retained local editor state/cache; not circuit or layout sources. |

Manual schematic arrangements and generated library edits are overwritten by
regeneration. Read the generator write map before using any writer.
**`tools/gen_pcb.py` without `--rules-only` is prohibited on this board.**
`load_pcb.py` preserves common footprint origins but changes parts/nets and
also runs the silkscreen writer; it does not certify routed copper preservation.

## Imported dependencies and setup

The tables point to **`../easyeda/EasyEDA.kicad_sym`** and
**`../easyeda/EasyEDA.pretty/`**. These are active, qualified imported
dependencies, including U1's FGG676 footprint. Models live in
`../easyeda/EasyEDA.3dshapes/`. Keep the `EasyEDA:` namespace and the exact
footprints. `tools/alloc.py`, `symlib.py`, `gen_kicad.py` and `load_pcb.py`
also reference those paths.

Imported model paths use a mixture of `${KIPRJMOD}`, `${KICAD_3RD_PARTY}` and
relative `easyeda/` paths. Where used, configure `KICAD_3RD_PARTY` to the
repository's `easyeda` directory in KiCad's path settings; it is unset in the
verification shell. Six of the live board's 39 distinct imported model paths
also name files absent from the repository even with that mapping (DFN-10,
ESOP-8, QFN-20, RJ45 L16.5, SMB L4.32 and WSON-8 L2.0). This is a pre-existing
3D-preview dependency gap. Relative `easyeda/` paths may require resolution
from the repository root. Cleanup preserves all model identifiers and files.
Stock symbols, footprints
and optional stock 3D models come from the KiCad installation. The small
`kicad/EasyEDA.*` copies remain in place; the project tables select the
`../easyeda/` versions. Do not treat their presence as another active project.

## Current layout and references

As checked on **2026-11-03** at cleanup baseline `3f76447`, the outline is
100 × 140 mm with 2 mm corner chamfers, eight layers, ENIG, nominal 1.6 mm,
JLC08161H-1080A: S / GND / S / PWR / GND / S / GND / S. The PCB has 555
footprints (551 schematic parts plus H1–H4), all origins in the outline's
bounding box and all assembly on F.Cu. There are no tracks or vias yet;
routing remains to be done. Five zones have saved fills: GND on In1/In4/In6,
and +3V3 plus the +1V0 island on In3. No refill was performed during cleanup.
